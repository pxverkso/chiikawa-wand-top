This model is a cosplay prop for the famed Japanese animation Chiikawa. I am publishing this under no official licensing and I am not affiliated with the original creators of this show. 

## Why I made this:
I figured it would be a fun project for me to work on as I am a huge fan of Chiikawa. I wanted to share it with other people so others could enjoy the prop as well. 

## Printing Instructions: 
It's crucial to print this model with a 0.4mm nozzle using 0.2mm layer heights as a different layer height and nozzle might mess with the tolerances of the parts. WARNING: The brackets may not fit together perfectly if printed with other settings. 
Please print the Horn Tip part 2 times to assemble the full model. Supports are needed for this print and I strongly recommend using manual supports with tree supports set on Organic.
